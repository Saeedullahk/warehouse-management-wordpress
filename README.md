# Warehouse Management System - WordPress

A complete inventory & warehouse management solution for traders in Bahawalpur, built with WordPress, WooCommerce & Custom PHP.

## 🚀 Features
- Stock IN / OUT tracking
- Multi-location warehouse support (Bahawalpur, Hasilpur, Yazman)
- Low stock email alerts
- Barcode / QR code support
- Staff role management
- Daily sales & purchase reports
- Urdu language support

## 🛠️ Tech Stack
- WordPress
- WooCommerce
- PHP 8, MySQL
- Elementor Pro

## 📦 Installation
1. Install WordPress
2. Install WooCommerce plugin
3. Clone this repo into wp-content/plugins/
4. Activate from WP Admin
